# OpenChess Academy Android APK

This Android wrapper opens the current OpenChess Academy GitHub Pages experience in an installable Android app.

## Included
- Human vs Echo Bot
- Human vs Human on the same device
- In-page Free Study Library

## Important
This initial APK loads the live HTTPS website in Android WebView. It needs an internet connection and does not provide full offline gameplay. Daily puzzles and live feeds depend on their upstream services.

## Build and install
Open the repository Actions tab and run the workflow named Build OpenChess Academy APK, or push changes to this folder. Download the artifact named OpenChess-Academy-debug-apk, extract it, and install app-debug.apk on your Android device. Android may ask you to allow installs from the app used to open the APK.

This is a debug-signed personal-use APK, not a Play Store release.
